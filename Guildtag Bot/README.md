# 🛡️ Discord Klan Etiketi (Guild Tag) Rol Botu

Bu bot, sunucunuzun özel klan etiketini (Guild Tag) profilinde taşıyan üyelere otomatik olarak rol verir, etiketi çıkaranlardan ise rolü geri alır. **Kullanıcı isminin başına yazılan yazılarla çalışmaz, sadece gerçek klan sistemiyle uyumludur.**

-----------------------------------------------------------------------

## 🚀 Kurulum Adımları

Botu çalıştırmak için kodlama bilmenize gerek yoktur. Sadece aşağıdaki adımları izleyin:
----------------------------------------------------------------------
### 1. Hazırlık
* Bilgisayarınızda **Python** yüklü olduğundan emin olun.
1. Adım Dosyanın Olduğu Klasörde Cmd'yi Açıp Şu Komutu Yazın          pip install -r requirements.txt
-----------------------------------------------------------------------
2. Adım Config.js Dosyasını Düzgün Şekilde Doldurun Doldurmanız Doğruysa Hiçbir Yanlışınız Yoksa Dosyanın Olduğu Klasörde Tekrar Cmd'yi Açıp python main.py yazın config.js dosyasını doğru doldurduysanız bot hatasız çalışır
